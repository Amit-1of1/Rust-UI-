### Changed

- **ui:** Atoll is built on Reshaped's foundations (MIT) with its own default look, "Lagoon": neutral greys on Reshaped's lightness steps, a lagoon-teal accent (`data-accent` unset is now teal, not black), Inter for text and headings (`--font-sans`, `--font-heading`, `--font-mono`), 10 px corners (`--radius: 0.625rem`, with `--radius-small|medium|large|full`; controls use medium) and a 2 px icon stroke. Menus, popovers, selects, dialogs, sheets and toasts float on the overlay surface with Reshaped's layered shadow; cards and the calendar use the raised shadow. Every component stylesheet takes its layers, transition speeds and easings, drop shadows, type sizes and weights from the new tokens. The old look is the `classic` preset. docs/BRAND.md and docs/FOUNDATIONS.md describe it. (#83)

### Added

- **ui:** Foundation tokens (docs/FOUNDATIONS.md): 4 px layout units `--unit-x1` ... `--unit-x24`; page grid `--layout-columns|gutter|margin|max-width` with breakpoints at 768, 1024 and 1280 px; a type scale `--font-size-*` / `--line-height-*` (display, title-1 to 4, body-1 to 3, caption-1; the largest grow from 768 px; every line height on the 4 px grid) and `--font-weight-*`; semantic colours `--color-background-*`, `--color-foreground-*`, `--color-border-*`, `--color-on-background-primary`; elevation surfaces `--color-background-elevation-base|raised|overlay` and `--shadow-raised|overlay`; a z-index scale `--z-index-raised` ... `--z-index-top`; motion `--duration-rapid|fast|medium|slow` (zeroed under reduced motion) and `--easing-standard|accelerate|decelerate`. `tests/foundations.rs` keeps component CSS on them. (#83)
- **ui:** Hover lift on buttons: filled and outlined buttons rise 1 px onto a soft shadow on hover (`--shadow-hover`, `--hover-lift`), primary and destructive with a glow in their own colour, a lit top edge in dark mode; pressing settles them back. Pointer devices only; no movement under reduced motion. (#83)
- **ui:** `Container`, `Stack`, `Grid`, `GridItem` and `Text` (the layout component): page container, spaced stacks on the unit scale, the responsive page grid and text on the type scale with semantic colours (experimental). (#83)
- **ui:** Theme presets ("looks"): `data-preset="reef|abyss|driftwood|classic"` (and `lagoon`, the default) switches colours, fonts, corner radius, density and icon stroke in one attribute, on `<html>` or any element. `ThemeStyles { preset: "reef" }` picks one at build time; `use_theme().set_preset(..)`, `preset()`, `preset_info()` and `radius_override()` switch at runtime; `PRESETS`, `PRESET_INFO` and the `PresetPicker` component; `ThemeCustomizer` shows the picker first; `PersistTheme` and `THEME_INIT_SCRIPT` remember the look (experimental). (#83)
- **ui:** Five OFL-1.1 fonts ship with the kit (`crates/ui/assets/fonts/`, Latin subsets of the variable Inter, Geist, IBM Plex Sans, Source Serif 4 and JetBrains Mono). `ThemeStyles` declares them with `font-display: swap`; a browser fetches a file only when the page uses it. `ThemeStyles { fonts: false }` and the `classic` preset use system fonts only. `ui::fonts` (experimental). (#83)
- **cli:** `atoll theme --preset <name>` prints a theme preset as the page default (`:root`), `--preset list` lists them. `atoll icons <words>` finds icons by name or by Lucide's search words; `atoll icons --reserved` lists the icons the kit keeps for one meaning. (#83)
- **docs:** Foundations guide (docs/FOUNDATIONS.md, the docs site's `#foundations`: colour, layout, typography, elevation, motion, iconography), Brand and looks guide (docs/BRAND.md, `#brand`), the Atoll mark (`docs/brand/atoll-mark.svg`, `atoll-logo.svg`), a look switcher in the docs and gallery headers, a "Five looks" section on the home page and a look picker on the theme builder. (#83)
