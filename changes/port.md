### Added

- **cli:** `atoll port <file.tsx>` and the MCP tool `port_jsx` turn shadcn/ui JSX into an Atoll `rsx!` starting point: kit components with their variant enums, Lucide icons, Tailwind classes as styles on theme tokens, and a list of handlers, lists, hooks and classes to finish by hand. See docs/PORTING.md.
- **docs:** "From shadcn" page (`#port`): paste shadcn JSX and see the Atoll code and the to-do list as you type; it runs the CLI's own translator in the browser.
