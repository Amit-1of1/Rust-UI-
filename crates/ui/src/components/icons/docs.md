# Icons

The kit's icons: every Lucide icon, plus Atoll's own set drawn for the stack (crates, wasm, desktop and mobile apps, agents and tool calls, charts, motion, focus), all generated into Rust as shape data plus one component per icon, so apps and components import icons from one place.

```rust
use ui::icons::{lucide, Icon, IconSize, Search, Trash};

rsx! {
    // Decorative (the default): the button text names the action.
    button { Trash { size: IconSize::Sm } "Delete" }
    // Icon-only control: name the control, not the SVG.
    button { "aria-label": "Search", Search { size: IconSize::Sm } }
    // An icon that carries meaning on its own gets a label (role="img").
    Icon { icon: lucide::BADGE_CHECK, label: "Verified" }
}
```

There are two ways to draw an icon. Each Lucide icon is a component (`Check`, `ChevronRight`), and also a constant with its shapes (`lucide::CHECK`) that `Icon` draws; use the constant when the icon is a value, such as a field in a nav item list. Old Lucide names (`AlertCircle` for `CircleAlert`) keep working.

Only the icons you name end up in your app's binary. `lucide::ALL` lists every icon; naming it pulls them all in, so keep it to tests and tools.

Import icons by path (`ui::icons::Check`), not with a glob: Lucide has icons named `Link`, `Badge`, `Calendar` and so on that would clash with the components.

## Atoll icons

`ui::icons::atoll` holds 558 original icons in the kit's own style (Feather-style like Reshaped: 2px stroke, 2px corners, round ends; the rendered stroke follows the theme), drawn on the same 24px grid as Lucide so the two mix in one row.

```rust
use ui::icons::{atoll, Icon, IconSize};

rsx! {
    button { atoll::Crate { size: IconSize::Sm } "Add crate" }
    // Standing alone and meaningful: use the icon's default accessible name.
    Icon { icon: atoll::AGENT, label: atoll::meta("agent").map(|m| m.label) }
}
```

- **Names say what an icon means**, not what it shows: `delete`, not `trash`; `next`, not `arrow-right`. Search words go in its keywords.
- **Every icon has a default accessible name** (`atoll::meta(name).label`), keywords and a category. `atoll::INDEX` lists them; it holds only strings, so naming it keeps no shapes in your binary.
- **Reserved icons** mean one action everywhere: `add`, `remove`, `close`, `delete`, `edit`, `copy`, `search`, `settings`, `menu`, `more`, `back`, `next`, `expand`, `collapse`, `download`, `upload`, `share`, `refresh`, the status icons and more. Don't use a reserved icon for anything else (no `delete` for "clear filter"; that's `close`).
- **Families:** common icons come with badge variants drawn on the same grid (`file-add`, `user-check`, `calendar-cancel`, `database-lock`, `image-ai`, `deploy-scheduled`) and switched-off variants (`microphone-off`, `wifi-off`, `notification-off`).
- The browser on this page searches names, default names and keywords, grouped into 20 categories (system, navigation, files, media, editor, commerce, maps, weather, devices, dev, agent and more).

## Size and stroke

- `size: IconSize::Sm` (and `Xs`, `Md`, `Lg`, `Xl`) read `--icon-size-sm` and friends from the theme. The default is `Lg`, 24px like Lucide's own.
- `size: 16` is pixels and `size: "1em"` any CSS length, when an icon must follow the text or a fixed box.
- The stroke is `--icon-stroke-width` (2) unless you pass `stroke_width`.
- Icons draw with `currentColor`, so they follow the text colour in both themes. Any other SVG attribute passes through (`class`, `style`, `"data-*"`).

## Right-to-left

Icons that point along the reading direction (arrows and chevrons that point left or right, undo and redo, reply, panel toggles, log in and out) are mirrored when they sit inside `dir="rtl"`. Pass `mirror_rtl: false` to keep one as drawn, or `mirror_rtl: true` to mirror another.

## Accessibility

- Role and name: icons are `aria-hidden="true"` unless you give them a `label`, which makes them `role="img"` with that name. Put the name of an icon-only button on the button (`aria-label` or `sr-only` text), not on the icon.
- Keyboard: not focusable.
- Reduced motion: icons do not animate.

## Stability

`Icon`, `IconData`, `IconNode`, `IconMeta`, everything in `atoll`, the `lucide` constants and the `label`, `mirror_rtl` and named `size` props are experimental. The icon component names (`ui::icons::Check`) are stable.

## Source

Atoll icons: drawn for this kit (MIT OR Apache-2.0, like the rest of it), one SVG each in `crates/ui/icons/atoll/` with their names and keywords in `icons.json`; `scripts/gen-atoll-icons.mjs` writes `atoll.rs`. Drawing rules are in `docs/ICONS.md`.

Lucide icons: generated by `scripts/gen-lucide-icons.mjs` from the `lucide-static` npm package (Lucide 1.57.0, ISC; the Feather-derived icons MIT). The licence is in the header of `lucide.rs` and in `crates/ui/LICENSE-lucide`. The choice is in `docs/ICONS.md`.
