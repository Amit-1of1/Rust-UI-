### Added

- **cli:** `rust-ui changelog` folds the per-PR fragments in `changes/` into CHANGELOG.md and docs/MIGRATION.md (`--check` validates them). `scripts/sync-main.sh` merges `main` into a branch and regenerates generated files; `scripts/check.sh` fails when a branch is behind `main` or edits the changelog directly. (#41)

### Changed

- **ui:** The kit's module lists, prelude and `ui::demos::ALL` (new: every demo by name) are generated by `crates/ui/build.rs` from the folders. Nothing public was added or removed. `rust-ui new` now only adds files (plus a gallery section); new component tests go in `crates/ui/tests/components/<name>.rs`.
