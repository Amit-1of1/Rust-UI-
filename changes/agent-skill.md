### Added

- **cli:** `rust-ui info [--json]` describes the app for coding agents: Dioxus requirement, theme and accent presets, installed items with edited, missing and conflicted files, and skill/MCP setup. Reads only the app (experimental). (#57)
- **cli:** `rust-ui skill` installs the kit's agent skill (`skills/rust-ui/SKILL.md`) into `.claude/skills/rust-ui/` (`--dest` for other agents, `--print` to print it). docs/MCP.md has the setup (experimental). (#57)
