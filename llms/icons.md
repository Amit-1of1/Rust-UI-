# Icons

- Copy into your app: `atoll add icons` or `dx components add icons --git https://github.com/Amit-1of1/Rust-UI-`.
- Import: `use crate::components::icons::*;` after copying, or `use ui::icons::{...};` (by path, no glob) with the `atoll-ui` crate.

The kit's one icon set: every Lucide icon, generated into Rust as shape data plus one component per icon, so apps and components import icons from one place.

```rust
use ui::icons::{lucide, Icon, IconSize, Search, Trash};

rsx! {
    // Decorative (the default): the button text names the action.
    button { Trash { size: IconSize::Sm } "Delete" }
    // Icon-only control: name the control, not the SVG.
    button { "aria-label": "Search", Search { size: IconSize::Sm } }
    // An icon that carries meaning on its own gets a label (role="img").
    Icon { icon: lucide::BADGE_CHECK, label: "Verified" }
}
```

There are two ways to draw an icon. Each Lucide icon is a component (`Check`, `ChevronRight`), and also a constant with its shapes (`lucide::CHECK`) that `Icon` draws; use the constant when the icon is a value, such as a field in a nav item list. Old Lucide names (`AlertCircle` for `CircleAlert`) keep working.

Only the icons you name end up in your app's binary. `lucide::ALL` lists every icon; naming it pulls them all in, so keep it to tests and tools.

Import icons by path (`ui::icons::Check`), not with a glob: Lucide has icons named `Link`, `Badge`, `Calendar` and so on that would clash with the components.

## Size and stroke

- `size: IconSize::Sm` (and `Xs`, `Md`, `Lg`, `Xl`) read `--icon-size-sm` and friends from the theme. The default is `Lg`, 24px like Lucide's own.
- `size: 16` is pixels and `size: "1em"` any CSS length, when an icon must follow the text or a fixed box.
- The stroke is `--icon-stroke-width` (2) unless you pass `stroke_width`.
- Icons draw with `currentColor`, so they follow the text colour in both themes. Any other SVG attribute passes through (`class`, `style`, `"data-*"`).

## Right-to-left

Icons that point along the reading direction (arrows and chevrons that point left or right, undo and redo, reply, panel toggles, log in and out) are mirrored when they sit inside `dir="rtl"`. Pass `mirror_rtl: false` to keep one as drawn, or `mirror_rtl: true` to mirror another.

## Accessibility

- Role and name: icons are `aria-hidden="true"` unless you give them a `label`, which makes them `role="img"` with that name. Put the name of an icon-only button on the button (`aria-label` or `sr-only` text), not on the icon.
- Keyboard: not focusable.
- Reduced motion: icons do not animate.

## Stability

`Icon`, `IconData`, `IconNode`, the `lucide` constants and the `label`, `mirror_rtl` and named `size` props are experimental. The icon component names (`ui::icons::Check`) are stable.

## Source

Generated by `scripts/gen-lucide-icons.mjs` from the `lucide-static` npm package (Lucide 1.57.0, ISC; the Feather-derived icons MIT). The licence is in the header of `lucide.rs` and in `crates/ui/LICENSE-lucide`. The choice is in `docs/ICONS.md`.

## API

```rust
/// One shape of an icon, in Lucide's 24×24 coordinate space. Values are kept as Lucide's text.
pub enum IconNode {
    /// `<path d>`.
    Path { d: &'static str },
    /// `<circle cx cy r>`; `filled` draws it with `fill="currentColor"` (a dot).
    Circle {
        cx: &'static str,
        cy: &'static str,
        r: &'static str,
        filled: bool,
    },
    /// `<ellipse cx cy rx ry>`.
    Ellipse {
        cx: &'static str,
        cy: &'static str,
        rx: &'static str,
        ry: &'static str,
    },
    /// `<rect x y width height rx ry>`.
    Rect {
        x: &'static str,
        y: &'static str,
        width: &'static str,
        height: &'static str,
        rx: Option<&'static str>,
        ry: Option<&'static str>,
    },
    /// `<line x1 y1 x2 y2>`.
    Line {
        x1: &'static str,
        y1: &'static str,
        x2: &'static str,
        y2: &'static str,
    },
    /// `<polyline points>`.
    Polyline { points: &'static str },
    /// `<polygon points>`.
    Polygon { points: &'static str },
}

/// One icon's shape data, as generated from Lucide: `ui::icons::lucide::CHECK`.
pub struct IconData {
    /// Lucide's name (`"chevron-right"`), also rendered as `data-icon`.
    pub name: &'static str,
    /// Whether the icon points along the reading direction and is mirrored in RTL text.
    pub mirror_rtl: bool,
    /// The shapes, drawn in order.
    pub nodes: &'static [IconNode],
}

/// Width and height of an icon. The named steps read `--icon-size-xs` … `--icon-size-xl`
/// from the theme; a number is pixels, and a string is any CSS length (`"1rem"`, `"1em"`).
///
/// The default, [`IconSize::Lg`], is 24px like Lucide's own.
pub enum IconSize {
    /// `--icon-size-xs` (0.75rem).
    Xs,
    /// `--icon-size-sm` (1rem): inside buttons, inputs and menus.
    Sm,
    /// `--icon-size-md` (1.25rem).
    Md,
    /// `--icon-size-lg` (1.5rem, 24px). The default.
    #[default]
    Lg,
    /// `--icon-size-xl` (2rem).
    Xl,
    /// A fixed width and height (`16`, `"1rem"`).
    Custom(AttributeValue),
}

/// Props of every per-icon component (`Check`, `ChevronRight`, ...).
pub struct IconProps {
    /// Width and height; a theme step ([`IconSize::Sm`]), pixels (`16`) or a CSS length (`"1rem"`).
    #[props(into, default)]
    pub size: IconSize,
    /// Accessible name. With one the icon is `role="img"`; without one it is `aria-hidden`.
    /// Leave it out when text next to the icon (or the control holding it) already says the same.
    #[props(into, default)]
    pub label: Option<String>,
    /// Override whether the icon mirrors in right-to-left text (default: the icon's own setting).
    #[props(default)]
    pub mirror_rtl: Option<bool>,
    /// Any SVG attribute (`stroke_width`, `class`, `style`, `"data-*"`), applied to the `<svg>`.
    #[props(extends = SvgAttributes)]
    pub attributes: Vec<Attribute>,
}

/// Props of [`Icon`]: the icon's shape data plus everything in [`IconProps`].
pub struct IconDataProps {
    /// The icon's shape data, from [`lucide`](super::lucide).
    pub icon: IconData,
    /// Width and height; a theme step ([`IconSize::Sm`]), pixels (`16`) or a CSS length.
    #[props(into, default)]
    pub size: IconSize,
    /// Accessible name. With one the icon is `role="img"`; without one it is `aria-hidden`.
    #[props(into, default)]
    pub label: Option<String>,
    /// Override whether the icon mirrors in right-to-left text.
    #[props(default)]
    pub mirror_rtl: Option<bool>,
    /// Any SVG attribute, applied to the `<svg>`.
    #[props(extends = SvgAttributes)]
    pub attributes: Vec<Attribute>,
}

/// Draws an icon from its shape data: `Icon { icon: lucide::CHECK, label: "Saved" }`.
///
/// Same props as the per-icon components; use this when the icon is a value (stored in a
/// list or chosen at runtime).
pub fn Icon(props: IconDataProps) -> Element

pub use lucide::components::*;
```

## Example

```rust
use crate::components::button::{Button, ButtonVariant, IconButton};
use crate::components::icons::{
    lucide, Bell, ChevronRight, Copy, Download, Heart, Icon, IconSize, Search, Settings, Star,
    Trash,
};
use dioxus::prelude::*;

#[component]
pub fn Demo() -> Element {
    rsx! {
        div { style: "display: flex; flex-direction: column; gap: 1rem;",
            // Decorative icons in a row: the label below each one is the text.
            ul {
                "aria-label": "Sample icons",
                style: "display: flex; flex-wrap: wrap; gap: 1rem; list-style: none; margin: 0; padding: 0;",
                IconCell { label: "Bell", Bell { size: "1.25rem", "aria-hidden": "true" } }
                IconCell { label: "Heart", Heart { size: "1.25rem", "aria-hidden": "true" } }
                IconCell { label: "Settings", Settings { size: "1.25rem", "aria-hidden": "true" } }
                IconCell { label: "Star", Star { size: "1.25rem", "aria-hidden": "true" } }
                IconCell { label: "Download", Download { size: "1.25rem", "aria-hidden": "true" } }
            }
            // Theme sizes (`--icon-size-*`), and an icon chosen at runtime from its data.
            div { style: "display: flex; gap: 0.75rem; align-items: end;",
                for size in [IconSize::Xs, IconSize::Sm, IconSize::Md, IconSize::Lg, IconSize::Xl] {
                    Icon { icon: lucide::SPARKLES, size }
                }
            }
            // A labelled icon is an image with a name; nothing else says "Verified" here.
            p { style: "display: flex; gap: 0.5rem; align-items: center; margin: 0;",
                "Ada Lovelace"
                Icon { icon: lucide::BADGE_CHECK, size: IconSize::Sm, label: "Verified" }
            }
            // Directional icons mirror in right-to-left text.
            div { style: "display: flex; gap: 1.5rem;",
                span { dir: "ltr", style: "display: inline-flex; gap: 0.25rem; align-items: center;",
                    "Next"
                    ChevronRight { size: IconSize::Sm }
                }
                span {
                    dir: "rtl",
                    lang: "ar",
                    style: "display: inline-flex; gap: 0.25rem; align-items: center;",
                    "التالي"
                    ChevronRight { size: IconSize::Sm }
                }
            }
            div { style: "display: flex; gap: 0.5rem; align-items: center;",
                Button { variant: ButtonVariant::Outline,
                    Copy { size: "1rem", "aria-hidden": "true" }
                    "Copy"
                }
                Button { variant: ButtonVariant::Destructive,
                    Trash { size: "1rem", "aria-hidden": "true" }
                    "Delete"
                }
                // Icon-only: `IconButton`'s required `label` carries the name.
                IconButton { label: "Search", variant: ButtonVariant::Ghost,
                    Search { size: "1rem", "aria-hidden": "true" }
                }
                // Or with hidden text (the theme's `sr-only` class), which translators and
                // find-in-page also see.
                Button { variant: ButtonVariant::Ghost,
                    Settings { size: "1rem", "aria-hidden": "true" }
                    span { class: "sr-only", "Settings" }
                }
            }
        }
    }
}

#[component]
fn IconCell(label: &'static str, children: Element) -> Element {
    rsx! {
        li { style: "display: flex; flex-direction: column; align-items: center; gap: 0.25rem; font-size: 0.75rem; color: var(--secondary-color-5);",
            {children}
            span { "{label}" }
        }
    }
}
```
