### Added

- **pro:** Atoll Pro v1 catalog (`docs/pro/CATALOG.md`, `docs/pro/catalog.json`, screenshots): 13 marketing blocks, the `reveal` and `number_ticker` motion components and a SaaS starter template. The sources live only in the private Pro repository.
- **scripts:** `scripts/pro-repo.sh <dir> --overlay <folder>` builds the Pro repository from this one plus a folder of Pro sources, checks every Pro folder carries `LICENSE-PRO.md`, regenerates the registry and commits.
- **ui:** the blocks module list is generated by `build.rs` like the components list, so a block (free here, or Pro in the Pro repository) is added by adding its folder.
