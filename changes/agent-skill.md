### Added

- **cli:** `atoll info [--json]` describes the app for coding agents: Dioxus requirement, theme and accent presets, installed items with edited, missing and conflicted files, and skill/MCP setup. Reads only the app (experimental). (#57)
- **cli:** `atoll skill` installs the kit's agent skill (`skills/atoll/SKILL.md`) into `.claude/skills/atoll/` (`--dest` for other agents, `--print` to print it). docs/MCP.md has the setup (experimental). (#57)
